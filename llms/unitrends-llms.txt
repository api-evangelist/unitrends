# Unitrends

> Unitrends, a Kaseya company, provides all-in-one backup and disaster recovery (BCDR) for data centers, cloud, SaaS, and endpoints. Its UniView / Unitrends MSP Portal exposes a read-only Public API (OAuth 2.0 client credentials) for appliances, protected assets, backups, customers, and BackupIQ alerts, and each Recovery Series / Unitrends Backup appliance exposes a documented REST API.

Generated by API Evangelist from apis.yml and repo artifacts on 2026-07-21 (no /llms.txt is published by the provider).

- [UniView Portal Public API reference (Swagger UI)](https://apidoc-public-api.backup.net/swagger-ui-v2/index.html): Interactive reference for the public API at https://public-api.backup.net
